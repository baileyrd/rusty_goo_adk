# rusty_goo_adk

A Rust port of [google/adk-python](https://github.com/google/adk-python) (Google's
Agent Development Kit) — same capability surface (agents, tools, flows, sessions,
models, planners, and the rest), rebuilt idiomatically in Rust rather than
transliterated.

## Status
Experimental — early migration in progress. Owner: [@baileyrd](https://github.com/baileyrd).
